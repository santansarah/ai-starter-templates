# AI Starter Templates

Working blueprints that AI coding assistants can reference when building new
firmware, Android, and iOS applications.

Keep this repository alongside your new project and point your AI assistant to
the relevant template. The assistant reads its code and guidance, then uses those
patterns to build your application in your own repository, guided by your
project's requirements.

| Folder | Template | Status |
| --- | --- | --- |
| [firmware](firmware/) | Nordic nRF52840 BLE firmware using nRF Connect SDK and Zephyr | Available |
| [android](android/) | Android applications | Planned |
| [ios](ios/) | iOS applications | Planned |

For example, when starting a firmware project in a fresh repository, tell your
AI assistant:

> Use the firmware template at `<path-to-ai-starter-templates>/firmware` as the
> architectural reference for building this project. Read its README,
> `AGENTS.md`, and source code, then follow its patterns while implementing this
> project's requirements in this repository.
